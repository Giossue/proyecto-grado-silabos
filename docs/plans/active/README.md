# Planes activos

Mantén aquí una carpeta o archivo por trabajo no trivial. Solo un plan puede afirmar que
es propietario de una migración o decisión concreta al mismo tiempo.

Al empezar:

1. copia la plantilla de `programming-plan.md`;
2. asigna un ID estable;
3. completa trazabilidad y decisiones;
4. divide pasos verificables;
5. actualiza el estado durante el trabajo.

Al cerrar, agrega evidencia y mueve el archivo a `../completed/`. No borres el historial.
