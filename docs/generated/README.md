# Referencias generadas

Este directorio puede contener artefactos derivados y reproducibles: esquemas, catálogos,
matrices o documentación generada desde código.

- Incluye en cada archivo el comando/origen y fecha de generación.
- No edites manualmente un archivo generado.
- No guardes secretos, datos productivos o documentos sensibles.
- Si la generación falla, corrige la fuente o el generador.
